## 🚀 Quick Install

1. **Click any download button above**  
2. Run `setup.exe` (Windows SmartScreen may appear – click *"More info"* then *"Run anyway"*)  
3. Follow the installer – it will place **ProjectFiles** in `%ProgramFiles%\VSCodiumDesktop`  
4. Launch from Start Menu or Desktop shortcut

## ❓ FAQ

**Q:** Is this the official VSCodium app?  
**A:** VSCodium is a community-driven binary distribution of VS Code without Microsoft branding or telemetry [citation:4].  

**Q:** Does it support VS Code extensions?  
**A:** Yes – VSCodium uses the Open VSX marketplace for extensions [citation:18].  

**Q:** Where are my settings stored?  
**A:** `%AppData%\VSCodium\settings.json` – you can backup or migrate manually.
